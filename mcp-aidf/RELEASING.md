# Releasing

`mcp-aidf` is released together with the other K-AIDF components from the repository root: one tag `vX.Y.Z` covers `agent-aidf`, `kobkob-kaidf-generator` and `mcp-aidf`, and components are not tagged or released on their own.

The steps, the version sites that `scripts/bump-version.sh` updates and what the release workflow verifies and builds are in the root [`RELEASING.md`](../RELEASING.md).
