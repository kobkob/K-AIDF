# Implantação

Esta seção reúne as receitas para colocar os componentes do K-AIDF em um servidor. Para rodar tudo na sua máquina, comece pela [instalação](../01-basics/instalacao.md).

| Receita | Componente | Quando usar |
|---|---|---|
| [EasyPanel](easypanel.md) | `mcp-aidf` | servir o MCP em um painel próprio, com HTTPS e volume persistente, a partir de um template |

Os arquivos das receitas ficam em [`deploy/`](../../deploy/), na raiz do repositório. A stack local de inferência (Ollama e LocalAI) está em [Provedores de inferência](../05-models/inference-providers.md).
